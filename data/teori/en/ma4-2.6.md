# The derivative of exponential and logarithmic functions

We go through yet another way of writing the derivative. If a function
$f(x)$ is to be differentiated, this can be written $D\big(f(x)\big)$, and so it means
the same thing as $f'(x)$. The advantage of this notation is that it is efficient,
since the expression to be differentiated can be inserted directly.

For example: $D(3x^2) = 6x$ or $D(x^2 - 5x + 3) = 2x - 5$.

A function where the variable is in the exponent is called an **exponential function**.
We derived the rules of differentiation for these in Mathematics continuation level 1c.

::: formel "The derivative of exponential functions"
$$
D(e^{kx}) = k\,e^{kx} \qquad\qquad D(a^x) = \ln a\cdot a^x
$$
:::

A function where the variable is inside a logarithm is called a **logarithmic function**.

::: formel "The derivative of the logarithmic function y = ln x"
$$
D(\ln x) = \frac{1}{x} \qquad \text{where } x > 0
$$
:::

## Derivation: the derivative of the logarithmic function y = ln x

We want to find the derivative of $y = \ln x$, that is $D(\ln x)$.

We do it with the help of the derivative of $y = x$, that is $D(x)$. If we
rewrite $x$ with the base $e$, then

$$
x = e^{\ln x}
$$

So

$$
D(x) = D\big(e^{\ln x}\big)
$$

We use the chain rule on the right-hand side and get

$$
D(x) = e^{\ln x}\cdot D(\ln x)
$$

Substituting $D(x) = 1$ and $e^{\ln x} = x$ gives

$$
1 = x\cdot D(\ln x)
$$

We solve for $D(\ln x)$ and get

$$
D(\ln x) = \frac{1}{x} \qquad \textbf{(QED)}
$$

::: exempel "Example 1: Differentiate using D notation"
**Find<br>a)&nbsp;$D(e^{3x})$&emsp;&emsp;b)&nbsp;$\dfrac{d}{dx}(5\ln x)$&emsp;&emsp;c)&nbsp;$\dfrac{d}{dt}(\ln t^4)$.**

::: handskrift
typ: dnotation
:::

::: textlosning
**a)** When we differentiate an exponential function with the base $e$, the derivative is
the same function multiplied by the inner derivative of the exponent. Here the
inner derivative is $3$:

$$
D(e^{3x}) = e^{3x}\cdot 3 = 3e^{3x}
$$

**b)** The operator $\dfrac{d}{dx}$ means that we should differentiate the following
expression with respect to $x$. Since the derivative of $\ln x$ is
$\dfrac{1}{x}$,

$$
\frac{d}{dx}(5\ln x) = 5\cdot \frac{1}{x} = \frac{5}{x}
$$

**c)** Here we have an outer function $\ln z$ where $z = t^4$ is the inner
function. The chain rule gives

$$
\frac{d}{dt}(\ln t^4) = \frac{1}{t^4}\cdot 4t^3 = \frac{4t^3}{t^4} = \frac{4}{t}
$$

**Answer:** a) $3e^{3x}$&emsp;&emsp;b) $\dfrac{5}{x}$&emsp;&emsp;c) $\dfrac{4}{t}$
:::
:::

::: exempel "Example 2: The chain rule in several steps"
**Differentiate<br>a)&nbsp;$y = \ln(3x - 4)^2$&emsp;&emsp;b)&nbsp;$y = e^{\sin x}$.**

::: handskrift
typ: kedjeflera
:::

::: textlosning
**a)** Here we have an outer function $\ln z$ where $z = (3x - 4)^2$ is the inner
function. Note that when we differentiate the inner function $(3x - 4)^2$, it
in turn has an inner function $(3x - 4)$. So we will get an inner
derivative of an inner derivative. The chain rule gives

$$
y' = \frac{1}{(3x - 4)^2}\cdot 2(3x - 4)\cdot 3
$$

$$
y' = \frac{6(3x - 4)}{(3x - 4)^2} = \frac{6}{3x - 4}
$$

**b)** We differentiate an outer function $e^z$ where $z = \sin x$ is the inner
function:

$$
y' = e^{\sin x}\cdot \cos x = \cos x\cdot e^{\sin x}
$$

**Answer:** a) $y' = \dfrac{6}{3x - 4}$&emsp;&emsp;b) $y' = \cos x\cdot e^{\sin x}$
:::
:::

::: sammanfattning "Summary"

::: sampunkt "D notation"
- $D\big(f(x)\big)$ means the same thing as $f'(x)$.
- The advantage is that the expression can be inserted directly: $D(3x^2) = 6x$.
- $\dfrac{d}{dx}$ similarly means "differentiate what follows, with respect to $x$".
:::

::: sampunkt "Exponential functions"
- $D(e^{kx}) = k\,e^{kx}$.
- $D(a^x) = \ln a \cdot a^x$.
- In a **logarithmic function** the variable is inside a logarithm.
:::

::: sampunkt "The logarithmic function"
- $D(\ln x) = \dfrac{1}{x}$, where $x > 0$.
- The proof: write $x = e^{\ln x}$ and differentiate both sides with the chain rule.
- Then $1 = x \cdot D(\ln x)$ directly gives the result.
:::

::: sampunkt "The chain rule in several steps"
- If the inner function in turn has an inner function, all the derivatives are multiplied in turn.
- $y = \ln(3x-4)^2$ gives $\dfrac{1}{(3x-4)^2} \cdot 2(3x-4) \cdot 3 = \dfrac{6}{3x-4}$.
- $y = e^{\sin x}$ gives $\cos x \cdot e^{\sin x}$.
- Simplify the answer at the end.
:::

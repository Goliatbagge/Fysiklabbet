# Numbers in decimal form

Our place value system is based on the base 10 and is called the **decimal
number system**. ("Decem" means 10 in Latin; compare, for example, with "decade",
which means ten years.) Depending on its position in the number, the digit stands for
different things.

## Rounding

A value that has been rounded is called an **approximate value**. The digit that is to be rounded
is called the **rounding digit**.

::: formel "The rounding rule"
| If the rounding digit is followed by … | … then … |
| --- | --- |
| 0, 1, 2, 3 or 4 | keep the rounding digit (round down) |
| 5, 6, 7, 8 or 9 | increase the rounding digit by 1 (round up) |
:::

::: exempel "Example 1: Rounding"
**Round 61.4738 to the nearest<br>a) tenth&emsp;&emsp;b) one&emsp;&emsp;c) ten**

::: handskrift
typ: avrundning
:::

::: textlosning
**a)** The digit 4 is the tenths digit. The digit *after* the four is 7, so the four
is increased by 1 (and becomes 5).

**Answer:** 61.5

**b)** The digit 1 is the ones digit. The digit *after* the one is 4, so the one
is kept.

**Answer:** 61 (Note that we cannot round in two steps from the answer to
part a, since that would have given 62.)

**c)** The digit 6 is the tens digit. The digit *after* the six is 1, so the six
is kept (and then we fill in with zeros).

**Answer:** 60
:::
:::

## Significant figures

When we solve tasks that describe real situations, we often need to
round. A measure of how precise an approximate value is is called **significant figures**,
and it controls how much we should round an answer.

Compare the sentences "the board is 4 metres" and "the board is 4.00 metres". Even though 4
and 4.00 are the same number, 4.00 indicates that we have measured the board more precisely.
4.00 has more significant figures!

::: formel "Number of significant figures in a number"
The first significant figure is the first digit in a number that is not 0. The
last significant figure is the last digit in the number. Zeros at the end of whole numbers
are not necessarily significant figures: it depends on whether they are rounding zeros
or not.
:::

Some examples:

| Number | Number of significant figures |
| --- | --- |
| 0.0238 | 3 |
| 0.02380 | 4 |
| 4 | 1 |
| 4.00 | 3 |
| 68 | 2 |
| 6 800 | 2, 3 or 4 |

::: formel "Number of significant figures in an answer"
In

- **multiplication and division**, the value with the fewest
  significant figures gives the number of **significant figures** in the answer (most common)
- **addition and subtraction**, the value with the fewest
  decimal places gives the number of **decimal places** in the answer.
:::

::: exempel "Example 2: Significant figures in multiplication"
**The front cover of a book is 19.5 cm × 24 cm. Find the area of the front cover.**

::: handskrift
typ: vardesiffror
:::

::: textlosning
$$
\text{area} = \text{base} \cdot \text{height} = 19.5 \cdot 24 = 468\ \mathrm{cm^2}
$$

We have done a multiplication, so we look at the number of significant figures. 19.5
has *three* significant figures and 24 has *two* significant figures. We round to the
*smallest number* of significant figures, that is, to two significant figures:

$$
\text{area} = 468\ \mathrm{cm^2} \approx 470\ \mathrm{cm^2}
$$

**Answer:** $470\ \mathrm{cm^2}$
:::
:::

::: exempel "Example 3: Decimal places in subtraction"
**You have a board that is 1.73 metres long and saw off 1.3 metres. How long is
the piece of board that is left?**

::: handskrift
typ: decimaler
:::

::: textlosning
$$
\text{length of the piece} = 1.73\ \mathrm{m} - 1.3\ \mathrm{m} = 0.43\ \mathrm{m}
$$

We have done a subtraction, so we look at the number of decimal places. 1.73 has
*two* decimal places and 1.3 has *one* decimal place. We round to the smallest
number of decimal places, that is, to one decimal place.

**Answer:** 0.4 m
:::
:::

::: sammanfattning "Summary"

::: sampunkt "The place value system"
- Our number system is based on the base 10 and is called the **decimal**
  number system.
- The **position** of the digit determines what it stands for: thousands, hundreds,
  tens, ones, tenths, hundredths and so on.
:::

::: sampunkt "Rounding"
- A rounded value is called an **approximate value**, the digit that is rounded the
  **rounding digit**.
- If it is followed by **0 to 4**: keep the digit, that is, round down.
- If it is followed by **5 to 9**: increase by 1, that is, round up.
- **Never round in two steps.** Always start from the original number.
:::

::: sampunkt "Significant figures"
- A measure of how **precise** a value is. 4.00 has more significant figures than
  4, even though the numbers are equal.
- The first significant figure is the first digit that is **not 0**. The last is
  the last digit of the number.
- Zeros at the end of a whole number can be rounding zeros, so 6 800 has
  2, 3 or 4 significant figures depending on the context.
:::

::: sampunkt "Significant figures in an answer"
- **Multiplication and division**: the answer gets as many
  **significant figures** as the value that has the fewest.
- **Addition and subtraction**: the answer gets as many **decimal places** as
  the value that has the fewest.
:::
:::

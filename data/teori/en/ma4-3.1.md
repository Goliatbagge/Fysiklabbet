# Antiderivatives

An **antiderivative** $F$ of a function $f$ is a function whose derivative
is $f$, that is $F'(x) = f(x)$. Finding an antiderivative is therefore the
reverse operation of differentiating. We review this from Mathematics continuation level 1c,
and then add the antiderivatives that follow from the new
differentiation rules at this level.

::: formel "Notation for antiderivatives"
If we have a function

$$
\begin{aligned}
f''(x) &\;\text{then the antiderivative is written}\; f'(x)\\
f'(x) &\;\text{then the antiderivative is written}\; f(x)\\
f(x) &\;\text{then the antiderivative is written}\; F(x)
\end{aligned}
$$
:::

If $F(x)$ is an antiderivative of $f(x)$, then so is $F(x) + C$ for
every constant $C$ (after all, a constant disappears when we differentiate). If we want to give **one**
antiderivative, a single expression is enough; if we are to give **all**
antiderivatives, we add the constant $C$, which can stand for any number at all.
For example, $f(x) = 2x$ has the antiderivative $F(x) = x^2$, and all
antiderivatives are given by $F(x) = x^2 + C$.

::: formel "Finding antiderivatives"
$$
\begin{aligned}
f(x) = x^n \quad&\Rightarrow\quad F(x) = \frac{x^{n+1}}{n+1}, \quad n \neq -1\\[4pt]
f(x) = k \quad&\Rightarrow\quad F(x) = kx\\[4pt]
f(x) = e^{kx} \quad&\Rightarrow\quad F(x) = \frac{e^{kx}}{k}\\[4pt]
f(x) = a^{kx} \quad&\Rightarrow\quad F(x) = \frac{a^{kx}}{k\cdot \ln a}
\end{aligned}
$$
:::

So a power function has its exponent increased by $1$, after which we divide
by the new exponent. A constant $k$ is multiplied by $x$. An
exponential function is copied and divided by the derivative of the exponent (and,
if the base is not $e$, also by $\ln$ of the base).

At this level we have covered some new differentiation rules, for example
$D(\sin x) = \cos x$, $D(\cos x) = -\sin x$ and $D(\ln x) = \dfrac{1}{x}$.
From these we can find more antiderivatives. Remember that for
the rules to hold for trigonometric functions, the angles must be given in
radians.

::: formel "Finding more antiderivatives"
$$
\begin{aligned}
f(x) = \sin x \quad&\Rightarrow\quad F(x) = -\cos x\\[4pt]
f(x) = \sin kx \quad&\Rightarrow\quad F(x) = -\frac{\cos kx}{k}\\[4pt]
f(x) = \cos x \quad&\Rightarrow\quad F(x) = \sin x\\[4pt]
f(x) = \cos kx \quad&\Rightarrow\quad F(x) = \frac{\sin kx}{k}\\[4pt]
f(x) = \frac{1}{x} \quad&\Rightarrow\quad F(x) = \ln x, \quad (x > 0)
\end{aligned}
$$
:::

In applications, the distance $s(t)$, the velocity $v(t)$ and the acceleration
$a(t)$ are linked. Differentiating takes us to the next quantity ($s \to v \to a$), and taking an
antiderivative takes us the other way ($a \to v \to s$).

::: exempel "Example 1: give an antiderivative"
**Give an antiderivative of<br>a)&nbsp;$f(x) = 5x^4 + \dfrac{1}{x}$&emsp;&emsp;b)&nbsp;$f(x) = e^{3x} - 5\cos x$**

::: handskrift
typ: primitivfunktion
:::

::: textlosning
a) We take an antiderivative term by term. The power term $5x^4$ has its
exponent raised by $1$ and is divided by the new exponent; $\dfrac{1}{x}$ gives
$\ln x$:

$$
F(x) = \frac{5x^5}{5} + \ln x = x^5 + \ln x
$$

b) The exponential term $e^{3x}$ is divided by the derivative of the exponent, $3$, and
$\cos x$ has the antiderivative $\sin x$:

$$
F(x) = \frac{e^{3x}}{3} - 5\sin x
$$

**Answer:** a) $x^5 + \ln x$&emsp;&emsp;b) $\dfrac{e^{3x}}{3} - 5\sin x$
:::
:::

::: exempel "Example 2: give all antiderivatives"
**Give all antiderivatives of<br>a)&nbsp;$f(x) = \dfrac{7}{x} + \dfrac{8}{x - 5}$&emsp;&emsp;b)&nbsp;$f(x) = \dfrac{x}{x^2 + 5x} - \dfrac{x^3 + 5x}{x^2}$**

::: handskrift
typ: samtligaprimitiva
:::

::: textlosning
a) Both terms are of the type $\dfrac{1}{x}$ (the second with $x - 5$ in the denominator),
so we get logarithms. When we give *all* antiderivatives we add
the constant $C$:

$$
F(x) = 7\ln x + 8\ln(x - 5) + C
$$

b) Here we have variables in both numerator and denominator. We first simplify each
term so that the variable is *only* in the numerator or *only* in the denominator:

$$
\frac{x}{x^2 + 5x} = \frac{x}{x(x + 5)} = \frac{1}{x + 5}
\qquad
\frac{x^3 + 5x}{x^2} = \frac{x^3}{x^2} + \frac{5x}{x^2} = x + \frac{5}{x}
$$

This gives

$$
f(x) = \frac{1}{x + 5} - \left(x + \frac{5}{x}\right) = \frac{1}{x + 5} - x - \frac{5}{x}
$$

Now we can find all antiderivatives by integrating term by term:

$$
F(x) = \ln(x + 5) - \frac{x^2}{2} - 5\ln x + C
$$

**Answer:** a) $7\ln x + 8\ln(x - 5) + C$&emsp;&emsp;b) $\ln(x + 5) - \dfrac{x^2}{2} - 5\ln x + C$
:::
:::

::: exempel "Example 3: from velocity to distance"
**A rocket is launched straight up and increases its speed according to the formula $v(t) = 3 + 0.9t^2$, where $t$ is the time in seconds after launch. The rocket is launched $1.5$ metres above the ground. At what height is the rocket after $4$ seconds?**

::: handskrift
typ: raketenhojd
:::

::: textlosning
We are to find the height $h$ from the formula for the velocity. The height is an
antiderivative of the velocity, so we start by finding all
antiderivatives of the velocity function:

$$
h(t) = 3t + \frac{0.9t^3}{3} + C = 3t + 0.3t^3 + C \qquad (1)
$$

To find the constant $C$ we use the fact that the rocket starts $1.5\ \mathrm{m}$ above the ground, that is the condition $h(0) = 1.5$:

$$
3\cdot 0 + 0.3\cdot 0^3 + C = 1.5 \quad\Leftrightarrow\quad C = 1.5
$$

Substituting $C = 1.5$ into $(1)$ gives

$$
h(t) = 3t + 0.3t^3 + 1.5
$$

Now we substitute the time $t = 4$ into the formula for the height:

$$
h(4) = 3\cdot 4 + 0.3\cdot 4^3 + 1.5 = 12 + 19.2 + 1.5 = 32.7
$$

**Answer:** After $4$ seconds the rocket is at a height of $32.7\ \mathrm{m}$.
:::
:::

::: sammanfattning "Summary"

::: sampunkt "Antiderivative"
- $F$ is an **antiderivative** of $f$ if $F'(x) = f(x)$.
- Integrating is the reverse operation of differentiating.
- For **one** antiderivative a single expression is enough. **All** of them require the constant $C$ to be added.
:::

::: sampunkt "The basic rules"
- $x^n \Rightarrow \dfrac{x^{n+1}}{n+1}$, where $n \neq -1$. Increase the exponent and divide by the new one.
- $k \Rightarrow kx$.
- $e^{kx} \Rightarrow \dfrac{e^{kx}}{k}$ and $a^{kx} \Rightarrow \dfrac{a^{kx}}{k \ln a}$.
:::

::: sampunkt "The new rules"
- $\sin x \Rightarrow -\cos x$ and $\sin kx \Rightarrow -\dfrac{\cos kx}{k}$.
- $\cos x \Rightarrow \sin x$ and $\cos kx \Rightarrow \dfrac{\sin kx}{k}$.
- $\dfrac{1}{x} \Rightarrow \ln x$, where $x > 0$. This is the exception to the power rule.
- The trigonometric rules require **radians**.
:::

::: sampunkt "Method"
- Integrate **term by term**, and simplify each term first.
- If the expression has variables in both numerator and denominator: split the fraction or cancel.
- Find $C$ from a condition, for example the starting height $h(0) = 1.5$.
- Integrate: $a(t) \rightarrow v(t) \rightarrow s(t)$. Differentiate the other way.
:::

:::

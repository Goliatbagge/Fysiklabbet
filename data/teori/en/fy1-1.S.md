# Summary: Introduction

This chapter was about the working methods and tools of physics: the
scientific method, and the SI system with its base units and prefixes.
After the chapter you should be able to calculate with the correct number of significant figures and switch between
prefixes and standard form.

## Concepts to know

- **The scientific method**: observation, hypothesis, testing the hypothesis,
  laws and theories.
- **Hypothesis**: a possible explanation that has not yet been tested.
- **Law**: a hypothesis that has been tested in several experiments without being disproved.
- **Theory**: several laws together; in physics a well-supported, certain
  relationship (not a guess as in everyday language).
- **Model**: a simplified description that agrees well enough with
  reality.
- **Quantity**: a property that can be measured with a numerical value and a unit, for example
  distance, time, force.
- **Numerical value**: the number a quantity is given with.
- **Unit**: the size of measure the numerical value is given in.
- **SI units**: the international system of units with seven base units
  (m, kg, s, A, K, mol, cd).
- **Prefix**: a scale factor in front of a unit (for example kilo, milli) that replaces
  a power of ten.
- **Significant figures**: the number of digits in a numerical value that carry meaning; decides
  how the answer should be rounded.
- **Standard form**: a number written as a factor between 1 and 10 times
  a power of ten, for example $2.5 \cdot 10^{6}$.

## Important relationships and methods

- If you calculate only with SI units in a formula, the answer is automatically in an
  SI unit. That is why it pays to convert to base units (m, kg, s)
  before you substitute values.
- Do **not** round until the end of a task. Otherwise the error in the answer
  can become large.
- The number of significant figures in the answer is decided by: for **multiplication/division**, the
  value with the **fewest** significant figures; for **addition/subtraction**, the
  value with the **fewest** decimal places.
- In standard form the first factor must be a number between 1 and 10; for
  numbers less than 1 the (negative) value of the exponent is given by the number of zeros before
  the first digit that is not 0.
- A prefix is just another way of writing a power of ten. Replace the
  power of ten with its prefix (or the other way round) without changing the value.

## Before the test

- Can you describe the four steps of the scientific method?
- Can you explain the difference between hypothesis, law and theory?
- Do you know the seven SI base units and which quantity each measures?
- Can you rewrite a number between prefix and standard form in both
  directions (for example μm ↔ $10^{-6}$ m)?
- Do you know how to decide the correct number of significant figures in an answer for multiplication/
  division and for addition/subtraction?
- Can you rewrite a large or small number in standard form?

# The graph of y = a sin x + b cos x

If we want to find the largest or the smallest value of a function of
the type $y = a \sin x + b \cos x$, it helps to first rewrite the expression
as a **single** trigonometric function. The sum of a sine term and a
cosine term is in fact always a shifted sine curve.

::: formel "Combining into a sine curve"
$$
y = a \sin x + b \cos x = c \sin (x + v)
$$

where the amplitude is

$$
c = \sqrt{a^2 + b^2} \qquad \text{and} \qquad \tan v = \frac{b}{a}
$$

Since the curve is a sine shape that is not shifted in the $y$-direction (it oscillates about
the $x$-axis), the **largest value** is $c$ and the **smallest value** is $-c$.
:::

Drag the sliders below and see how $a$ and $b$ together form a single
sine curve. With $a = 5$ and $b = 12$ the amplitude is
$c = \sqrt{5^2 + 12^2} = \sqrt{169} = 13$: the curve reaches at most 13
and at least $-13$.

::: exempel "Example 1: Amplitude, largest and smallest value"
**The function $y = 4 \sin x + 3 \cos x$ is given. Find its<br>a) amplitude&emsp;&emsp;b) largest value&emsp;&emsp;c) smallest value.**

::: handskrift
typ: amplitudsum
:::

::: textlosning
**a)** We compare $y = 4 \sin x + 3 \cos x$ with $y = a \sin x + b \cos x$ and
identify $a = 4$ and $b = 3$. We rewrite the function in the form
$y = c \sin (x + v)$:

$$
c = \sqrt{a^2 + b^2} = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5
$$

so $y = 5 \sin (x + v)$. The amplitude is the absolute value of the factor in front of the
trigonometric function, that is $|5| = 5$.

**Answer a):** the amplitude is 5

**b)** The largest value is the same as the amplitude, since the function is not
shifted in the $y$-direction.

**Answer b):** the largest value is 5

**c)** The smallest value is the negative of the amplitude.

**Answer c):** the smallest value is $-5$
:::
:::

::: exempel "Example 2: Find a for a given amplitude"
**Find $a$ so that the function $y = a \sin x + 12 \cos x$ has the amplitude 13.**

::: handskrift
typ: bestamamplitud
:::

::: textlosning
We rewrite the function so that it consists of a single trigonometric expression
according to the formula above:

$$
y = \sqrt{a^2 + 12^2} \cdot \sin (x + v)
$$

The factor in front of the trigonometric function, in this case
$\sqrt{a^2 + 12^2}$, gives the amplitude. It must be 13:

$$
\sqrt{a^2 + 12^2} = 13
$$

We square both sides and solve for $a$:

$$
a^2 + 12^2 = 13^2 \quad\Leftrightarrow\quad a^2 + 144 = 169 \quad\Leftrightarrow\quad a^2 = 25
$$

$$
a = \pm\sqrt{25} = \pm 5
$$

**Answer:** $a = \pm 5$
:::
:::

::: exempel "Example 3: From a shifted sine to a sin x + b cos x"
**Let $f(x) = 4 \sin\!\left(x + \dfrac{\pi}{6}\right)$. Give the function expression in the form $f(x) = a \sin x + b \cos x$ where $a, b > 0$.**

::: handskrift
typ: tillsincos
:::

::: textlosning
We compare the expression $4 \sin\!\left(x + \dfrac{\pi}{6}\right)$ with
$c \sin (x + v)$ to identify $c$ and $v$. Identification gives $c = 4$
and $v = \dfrac{\pi}{6}$. Now we use the two relationships backwards.

Since $c = \sqrt{a^2 + b^2}$, this gives

$$
4 = \sqrt{a^2 + b^2} \quad\Leftrightarrow\quad 16 = a^2 + b^2 \qquad (1)
$$

Since $\tan v = \dfrac{b}{a}$, this gives

$$
\tan\!\left(\frac{\pi}{6}\right) = \frac{b}{a} \quad\Leftrightarrow\quad \frac{1}{\sqrt{3}} = \frac{b}{a} \qquad (2)
$$

We form a system of equations from (1) and (2). From the lower equation we get
$a = b\sqrt{3}$, which we substitute into the upper one:

$$
16 = (b\sqrt{3})^2 + b^2 = 3b^2 + b^2 = 4b^2 \quad\Leftrightarrow\quad b^2 = 4
$$

$$
b = \sqrt{4} = 2
$$

(the negative solution is disregarded since $b > 0$). Substituting $b = 2$ into
$a = b\sqrt{3}$ gives $a = 2\sqrt{3}$. So:

$$
f(x) = 2\sqrt{3}\,\sin x + 2 \cos x
$$

**Answer:** $f(x) = 2\sqrt{3}\,\sin x + 2 \cos x$
:::
:::

::: sammanfattning "Summary"

::: sampunkt "Combining"
- $y = a\sin x + b\cos x = c\sin(x + v)$.
- A sum of a sine term and a cosine term is always a **shifted sine curve**.
- $c = \sqrt{a^2 + b^2}$ and $\tan v = \dfrac{b}{a}$.
:::

::: sampunkt "Largest and smallest value"
- The amplitude is $c$, since the curve oscillates about the $x$-axis without a shift in the $y$-direction.
- The largest value is $c$ and the smallest value is $-c$.
- $y = 4\sin x + 3\cos x$ gives $c = \sqrt{16 + 9} = 5$, so the largest value is 5 and the smallest $-5$.
:::

::: sampunkt "Finding a coefficient"
- Set $\sqrt{a^2 + b^2}$ equal to the given amplitude.
- Square both sides and solve for the unknown.
- Remember that the square root gives **two** solutions, $a = \pm 5$, unless a condition rules one out.
:::

::: sampunkt "The other way round"
1. Identify $c$ and $v$ from $c\sin(x + v)$.
2. Set up $c^2 = a^2 + b^2$ and $\tan v = \dfrac{b}{a}$.
3. Solve the system of equations.
- $4\sin\left(x + \dfrac{\pi}{6}\right)$ becomes $2\sqrt{3}\sin x + 2\cos x$.
:::

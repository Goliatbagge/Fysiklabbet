# Euler's formula and the number eᶻ

To describe the relationship between the exponential function and the
trigonometric functions for a complex number, **Euler's formula** is used.
It links together two seemingly completely different parts of mathematics: powers with
base $e$ on the one hand, and cosine and sine on the other.

::: formel "Euler's formula"
For all real numbers $v$,
$$
e^{iv} = \cos v + i\sin v
$$
:::

## Making Euler's formula plausible

A complete proof of Euler's formula requires more advanced mathematics
(Maclaurin expansions). We can, however, make it plausible by showing that the two
sides have the same basic properties. We let $f(v) = e^{iv}$ and
$g(v) = \cos v + i\sin v$.

**Property 1: the value when $v = 0$.** Both functions start at the same point:

$$
\begin{aligned}
f(0) &= e^{i\cdot 0} = e^0 = 1\\
g(0) &= \cos 0 + i\sin 0 = 1 + i\cdot 0 = 1
\end{aligned}
$$

**Property 2: the derivative.** Both functions are differentiated by
multiplying the original function by the number $i$:

$$
\begin{aligned}
f'(v) &= i\,e^{iv} = i\cdot f(v)\\
g'(v) &= -\sin v + i\cos v = i\cos v + i^2\sin v = i(\cos v + i\sin v) = i\cdot g(v)
\end{aligned}
$$

Two functions that start at the same value and then follow the same
differentiation rule ought to be the same function. This makes it plausible that
$e^{iv} = \cos v + i\sin v$.

## Euler's identity

We get a direct consequence of Euler's formula if we set $v = \pi$. Since
$\cos \pi = -1$ and $\sin \pi = 0$,

$$
e^{i\pi} = \cos \pi + i\sin \pi = -1 + 0 = -1
$$

::: formel "Euler's identity"
$$
e^{i\pi} = -1 \qquad \text{or} \qquad e^{i\pi} + 1 = 0
$$
:::

Euler's identity is often regarded as "the most beautiful equation in the world", since
it unites, in a surprisingly simple way, five of the most
fundamental constants of mathematics, $0$, $1$, $e$, $i$ and $\pi$, from completely different
branches of mathematics in a single, elegant relationship.

## Complex numbers in exponential form

When we describe complex numbers using the base $e$, it is called **exponential
form**. We already know that a complex number in polar form is written
$z = r(\cos v + i\sin v)$. If we substitute Euler's formula
$\cos v + i\sin v = e^{iv}$ into the polar form, we get the exponential
form directly.

::: formel "Complex numbers in exponential form"
A complex number $z$ in exponential form is written
$$
z = r\,e^{iv} \qquad \text{where } r = |z| = \sqrt{a^2 + b^2} \ \text{ and } \ v = \arg z
$$
:::

So one and the same complex number can be written in three different ways, all with
the same modulus $r$ and the same argument $v$.

::: formel "Complex numbers in three forms"
$$
\begin{aligned}
z &= a + bi && \text{rectangular form}\\
z &= r(\cos v + i\sin v) && \text{polar form}\\
z &= r\,e^{iv} && \text{exponential form}
\end{aligned}
$$
:::

In the complex plane, $e^{iv}$ (that is, $r = 1$) corresponds to a point on
the unit circle: its real part is $\cos v$ and its imaginary part is $\sin v$.

## The number eᶻ for a complex z

When the exponent itself is a complex number, $z = a + bi$, we split the power
using the laws of exponents: $e^{a + bi} = e^a\cdot e^{bi}$. The factor $e^a$ is an ordinary
real number, and $e^{bi}$ is rewritten with Euler's formula (here $r = 1$ and
the angle is $b$).

::: formel "Rewriting from exponential to rectangular form"
$$
e^{a + bi} = e^a\cdot e^{bi} = e^a(\cos b + i\sin b)
$$
:::

::: exempel "Example 1: Write z in the form a + bi"
**Write the numbers in the form $z = a + bi$.**
<br>a)&nbsp;$z = 4e^{i\frac{\pi}{3}}$&emsp;&emsp;b)&nbsp;$z = e^{4 + i\frac{\pi}{2}}$&emsp;&emsp;c)&nbsp;$z = e^{i(\pi - 3i)}$

::: handskrift
typ: eulerform
:::

::: textlosning

**a)** We compare $z = 4e^{i\frac{\pi}{3}}$ with the exponential form
$z = r\,e^{iv}$ and see that $r = 4$ and $v = \dfrac{\pi}{3}$. Substituting into the
polar form $z = r(\cos v + i\sin v)$ gives:

$$
z = 4\left(\cos \frac{\pi}{3} + i\sin \frac{\pi}{3}\right) = 4\left(\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) = 4\cdot \frac{1}{2} + 4i\frac{\sqrt{3}}{2} = 2 + 2i\sqrt{3}
$$

**b)** If the exponent has a real part, it can be factored out as a separate power
according to the laws of exponents. The factor $e^{i\frac{\pi}{2}}$ is written in polar form with
$r = 1$ and $v = \dfrac{\pi}{2}$:

$$
z = e^{4 + i\frac{\pi}{2}} = e^4\cdot e^{i\frac{\pi}{2}} = e^4\left(\cos \frac{\pi}{2} + i\sin \frac{\pi}{2}\right) = e^4(0 + i\cdot 1) = e^4 i
$$

**c)** We first expand the bracket in the exponent (remember that $i^2 = -1$):

$$
z = e^{i(\pi - 3i)} = e^{i\pi - 3i^2} = e^{i\pi + 3} = e^{i\pi}\cdot e^3
$$

Euler's identity $e^{i\pi} = -1$ gives:

$$
z = (-1)\cdot e^3 = -e^3
$$

**Answer:** a) $z = 2 + 2i\sqrt{3}$&emsp;&emsp;b) $z = e^4 i$&emsp;&emsp;c) $z = -e^3$
:::
:::

::: exempel "Example 2: Find a solution to an equation"
**Find a solution to $e^z = -3i$.**

::: handskrift
typ: eulerekvation
:::

::: textlosning
We write both sides in polar form. On the left-hand side the exponent is complex,
$z = a + bi$:

$$
\text{LHS} = e^z = e^{a + bi} = e^a\cdot e^{bi} = e^a(\cos b + i\sin b)
$$

The right-hand side $-3i$ has the modulus $r = |-3i| = 3$ and the argument $v = \dfrac{3\pi}{2}$
(the angle of the arrow in the complex plane):

$$
\text{RHS} = -3i = 3\left(\cos \frac{3\pi}{2} + i\sin \frac{3\pi}{2}\right)
$$

This gives the equation

$$
e^a(\cos b + i\sin b) = 3\left(\cos \frac{3\pi}{2} + i\sin \frac{3\pi}{2}\right)
$$

Comparing the moduli and arguments gives:

$$
e^a = 3 \quad\Leftrightarrow\quad a = \ln 3 \qquad\text{and}\qquad b = \frac{3\pi}{2}
$$

Substituting into $z = a + bi$ gives the solution.

**Answer:** $z = \ln 3 + \dfrac{3\pi}{2}i$
:::
:::

::: sammanfattning "Summary"

::: sampunkt "Euler's formula"
- $e^{iv} = \cos v + i\sin v$ for all real $v$.
- It links the exponential function with the trigonometric functions.
- Made plausible by both sides having the same starting value and the same derivative, namely the function itself times $i$.
:::

::: sampunkt "Euler's identity"
- Set $v = \pi$: since $\cos \pi = -1$ and $\sin \pi = 0$, $e^{i\pi} = -1$.
- Also written $e^{i\pi} + 1 = 0$.
- Called the most beautiful equation in the world, since it unites $0$, $1$, $e$, $i$ and $\pi$.
:::

::: sampunkt "Three forms"
- **Rectangular:** $z = a + bi$
- **Polar:** $z = r(\cos v + i\sin v)$
- **Exponential:** $z = r\,e^{iv}$
- All three have the same modulus $r$ and the same argument $v$.
:::

::: sampunkt "Calculating with exponential form"
- If the exponent has a real part: split it using the laws of exponents, $e^{a + bi} = e^a \cdot e^{bi}$.
- Then $e^a$ is the modulus and $b$ the argument.
- Solve equations by writing both sides in polar form and **comparing** modulus and argument.
- $e^z = -3i$ gives $e^a = 3$ and $b = \dfrac{3\pi}{2}$, so $z = \ln 3 + \dfrac{3\pi}{2}i$.
:::

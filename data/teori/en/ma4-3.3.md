# Rules for integrals

To make certain integral calculations easier, where we have addition and
subtraction in the expression to be integrated or where we have multiplication
by a constant, there are calculation rules. They let us break up a complicated
integral into several simpler ones, just like the corresponding rules for derivatives.

::: formel "Rules for integrals"
$$
\begin{aligned}
\int_a^c f(x)\,dx &= \int_a^b f(x)\,dx + \int_b^c f(x)\,dx\[4pt]
\int_a^b \bigl(f(x) + g(x)\bigr)\,dx &= \int_a^b f(x)\,dx + \int_a^b g(x)\,dx\[4pt]
\int_a^b \bigl(f(x) - g(x)\bigr)\,dx &= \int_a^b f(x)\,dx - \int_a^b g(x)\,dx\[4pt]
\int_a^b k\cdot f(x)\,dx &= k\cdot \int_a^b f(x)\,dx \qquad (k \text{ constant})
\end{aligned}
$$
:::

In turn, the rules say that: an integral can be split into
subintervals that are joined together ($a \to b \to c$), that an integral of a **sum**
or **difference** can be calculated term by term, and that a **constant factor** can
be taken out in front of the integral sign. The constant $k$ must not contain any
variable; it has to be independent of $x$.

If we swap the two limits of integration, the integral changes sign:

$$
\int_a^b f(x)\,dx = -\int_b^a f(x)\,dx
$$

::: exempel "Example 1: join two intervals"
**Calculate $\displaystyle\int_0^{\pi/2}\sin 2x\,dx + \int_{\pi/2}^{\pi}\sin 2x\,dx$.**

::: handskrift
typ: fogaintegraler
:::

::: textlosning
Since we have the same function and the limits of integration in the two integrals
are connected ($0 \to \dfrac{\pi}{2} \to \pi$), we can write them as a
single integral:

$$
\int_0^{\pi/2}\sin 2x\,dx + \int_{\pi/2}^{\pi}\sin 2x\,dx = \int_0^{\pi}\sin 2x\,dx
$$

We then calculate the integral as usual. An antiderivative of $\sin 2x$
is $-\dfrac{\cos 2x}{2}$:

$$
\int_0^{\pi}\sin 2x\,dx = \left[-\frac{\cos 2x}{2}\right]_0^{\pi} = -\frac{\cos 2\pi}{2} - \left(-\frac{\cos 0}{2}\right) = -\frac{1}{2} + \frac{1}{2} = 0
$$

**Answer:** $0$
:::
:::

::: exempel "Example 2: take out a constant factor"
**Calculate $\displaystyle\int_0^{\pi/2} 5\sin 2x\,dx$.**

::: handskrift
typ: brytutkonstant
:::

::: textlosning
We "take out" the factor that does not contain any variable ($5$). This gives:

$$
\int_0^{\pi/2} 5\sin 2x\,dx = 5\cdot \int_0^{\pi/2}\sin 2x\,dx
$$

We then calculate the integral as usual:

$$
\begin{aligned}
5\cdot \int_0^{\pi/2}\sin 2x\,dx &= 5\left[-\frac{\cos 2x}{2}\right]_0^{\pi/2} = 5\left(-\frac{\cos \pi}{2} - \left(-\frac{\cos 0}{2}\right)\right)\[4pt]
&= 5\left(\frac{1}{2} + \frac{1}{2}\right) = 5\cdot 1 = 5
\end{aligned}
$$

**Answer:** $5$
:::
:::

::: exempel "Example 3: split an integral of several terms"
**Calculate $\displaystyle\int_1^{2}\left(4x^3 + \frac{5}{x}\right)dx$ and $\displaystyle\int_1^{2}\left(4x^3 - \frac{5}{x}\right)dx$.**

::: handskrift
typ: delaintegral
:::

::: textlosning
The expression to be integrated consists of several terms. To get a
less complex calculation we split it into two simpler integrals:

$$
\int_1^{2}\left(4x^3 + \frac{5}{x}\right)dx = \int_1^{2} 4x^3\,dx + \int_1^{2}\frac{5}{x}\,dx
$$

We calculate each integral separately:

$$
\int_1^{2} 4x^3\,dx = \left[\frac{4x^4}{4}\right]_1^{2} = \left[x^4\right]_1^{2} = 2^4 - 1^4 = 16 - 1 = 15
$$

$$
\int_1^{2}\frac{5}{x}\,dx = \Bigl[5\ln x\Bigr]_1^{2} = 5\ln 2 - 5\ln 1 = 5\ln 2 - 0 = 5\ln 2
$$

We now add these together:

$$
\int_1^{2} 4x^3\,dx + \int_1^{2}\frac{5}{x}\,dx = 15 + 5\ln 2
$$

In the same way we split the second integral with the subtraction rule. With
the same partial integrals as above we get:

$$
\int_1^{2}\left(4x^3 - \frac{5}{x}\right)dx = \int_1^{2} 4x^3\,dx - \int_1^{2}\frac{5}{x}\,dx = 15 - 5\ln 2
$$

**Answer:** $15 + 5\ln 2$ and $15 - 5\ln 2$ respectively
:::
:::

::: sammanfattning "Summary"

::: sampunkt "The rules"
- $\int_a^c f = \int_a^b f + \int_b^c f$. An integral can be **split into subintervals**.
- $\int_a^b (f + g) = \int_a^b f + \int_a^b g$, and the same with a minus sign.
- $\int_a^b k \cdot f(x)\,dx = k \int_a^b f(x)\,dx$, where $k$ is a constant.
:::

::: sampunkt "The condition on the constant"
- The factor $k$ must **not** contain any variable.
- It has to be independent of $x$ to be moved out in front of the integral sign.
:::

::: sampunkt "Swapping limits"
- If you swap the limits of integration, the integral changes **sign**.
- $\int_a^b f = -\int_b^a f$.
:::

::: sampunkt "Why the rules help"
- A complicated integral can be broken up into several simple ones, one per term.
- Calculate each partial integral separately and add the results at the end.
- $\int_1^2 \left(4x^3 + \dfrac{5}{x}\right)dx = 15 + 5\ln 2$.
:::

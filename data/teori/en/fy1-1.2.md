# Quantities, units and prefixes

## Quantities and units

A property that can be measured is called a **[[quantity|A property that can be measured with a number and a unit, for example distance, time, force.]]**. The numerical value the quantity
is given with is called the **numerical value**. The size of measure that the numerical value is given in is called the
**unit**.

The sentence "the [[distance|The total length of path an object has moved. A scalar quantity, measured in metres.]] is 2 500 metres" contains the quantity *distance*, the numerical value
*2 500* and the unit *metre*.

Quantities are usually given a symbol that is used in formulas. For example,
distance is often written *s*, [[force|An influence that can change the motion or shape of an object. SI unit newton (N). A vector quantity.]] *F* and [[velocity|Change of position per unit time, with direction (a vector). SI unit m/s.]] *v*. You may use other
symbols, but it helps to use the generally accepted ones.

There can be different units for the same quantity. Distance can be given in, for example, metres,
centimetres, Swedish miles (10 km), inches, light years, furlongs and so on. That is why the
international **[[SI units|The International System of Units, with seven base units (m, kg, s, A, K, mol, cd).]]** were introduced. If we calculate with SI units in formulas, the
answer will always be in an SI unit too. The SI units are built on seven
**base units**.

| Quantity | Base unit | Symbol |
| --- | --- | --- |
| length | metre | m |
| mass | kilogram | kg |
| time | second | s |
| electric current | ampere | A |
| temperature | kelvin | K |
| amount of substance | mole | mol |
| luminous intensity | candela | cd |

All other units can be constructed from these base units.

::: exempel "Example 1: SI unit for velocity and volume"
**What is the SI unit for<br>a) velocity&emsp;&emsp;b) volume?**

::: handskrift
typ: sienhet
:::

::: textlosning
**a)** Velocity is calculated as distance / time. Since the SI unit for distance is the
metre and the SI unit for time is the second, the SI unit for velocity is

$$
\frac{\text{distance}}{\text{time}}
= \left[\frac{\text{metre}}{\text{second}}\right]
= \left[\frac{\text{m}}{\text{s}}\right] = [\mathrm{m/s}]
$$

**Answer:** m/s

**b)** Volume is calculated from distance in three dimensions. Since the SI unit
for distance is the metre, the SI unit for volume is

$$
\text{distance} \cdot \text{distance} \cdot \text{distance}
= [\text{m} \cdot \text{m} \cdot \text{m}] = [\mathrm{m^3}]
$$

**Answer:** m³
:::
:::

::: härledning "Note 1: Rounding"
Numerical values are important. Do not round until the *end* of a task, otherwise the
error can become large!
:::

::: härledning "Note 2: Significant figures"
Remember to answer with the correct number of **significant figures**.

| Operation | The number of significant figures is given by … |
| --- | --- |
| Multiplication and division | … the value with the fewest significant figures |
| Addition and subtraction | … the value with the fewest decimal places |
:::

A cheat sheet for how to solve physics problems in a structured way can be found
in the course material.
:::

::: exempel "Example 2: Svetlana's average speed"
**Svetlana runs 56 metres in 7.12 seconds. What is her [[average speed|Total distance travelled divided by total time. Has no direction (a scalar).]]?**

::: handskrift
typ: medelfart
:::

::: textlosning
We write down the formula for average speed.

$$
v_\mathrm{m} = \frac{s}{t}
$$

$$
\left[ \begin{array}{l}
s = 56\ \mathrm{m} \\
t = 7.12\ \mathrm{s}
\end{array} \right]
$$

$$
v_\mathrm{m} = \frac{56\ \mathrm{m}}{7.12\ \mathrm{s}} = 7.865\ldots\ \mathrm{m/s}
$$

The numerical value 56 has **two** significant figures and the numerical value 7.12 has **three**
significant figures, so we should round to two significant figures (the fewest
significant figures).

$$
v_\mathrm{m} = 7.865\ldots\ \mathrm{m/s} \approx 7.9\ \mathrm{m/s}
$$

**Answer:** 7.9 m/s
:::
:::

## Prefixes and powers of ten

Prefixes and powers of ten are often used to make it easier to write an answer
(especially for large or small numbers). The most common prefixes are in the
table below.

| Power of ten | Name | Prefix | | Power of ten | Name | Prefix |
| --- | --- | --- | --- | --- | --- | --- |
| 10³ | kilo | k | | 10⁻¹ | deci | d |
| 10⁶ | mega | M | | 10⁻² | centi | c |
| 10⁹ | giga | G | | 10⁻³ | milli | m |
| 10¹² | tera | T | | 10⁻⁶ | micro | μ |
| 10¹⁵ | peta | P | | 10⁻⁹ | nano | n |
| 10¹⁸ | exa | E | | 10⁻¹² | pico | p |
| 10²¹ | zetta | Z | | 10⁻¹⁵ | femto | f |
| 10²⁴ | yotta | Y | | 10⁻¹⁸ | atto | a |

::: exempel "Example 3: Standard form and prefixes"
**Write 0.000 002 4 metres<br>a) in standard form&emsp;&emsp;b) with a prefix.**

::: handskrift
typ: prefixmeter
:::

::: textlosning
**a)** In standard form the first factor must be a number between 1 and 10.
In this case it is 2.4. For small numbers, less than 1, the exponent of the power of ten is given
by the number of zeros before the first digit that is not 0, with a
minus sign. In this case we have 6 zeros at the start of the number, so the exponent
is −6.

**Answer:** 2.4 · 10⁻⁶ m

**b)** We look at the number in standard form and study the power of ten.
The power of ten 10⁻⁶ has the prefix μ (micro). We replace the power of ten with its
prefix.

**Answer:** 2.4 μm
:::
:::

::: sammanfattning "Summary"

::: sampunkt "Quantity, numerical value and unit"
- **Quantity**: a property that can be measured, for example distance.
- **Numerical value**: the number.
- **Unit**: the measure the numerical value is given in.
- "The distance is 2 500 metres" has the quantity distance, the numerical value 2 500 and
  the unit metre.
- Quantities get symbols in formulas: $s$ for distance, $F$ for force,
  $v$ for velocity.
:::

::: sampunkt "The seven base units of the SI system"
- metre (m), kilogram (kg), second (s), ampere (A), kelvin (K),
  mole (mol) and candela (cd).
- All other units are built from these. Velocity becomes m/s, volume becomes m³.
- If you calculate with SI units in a formula, the answer is automatically in an
  SI unit.
:::

::: sampunkt "Significant figures"
- **Multiplication and division**: the answer gets as many significant figures as
  the value that has the **fewest significant figures**.
- **Addition and subtraction**: as many **decimal places** as the value with
  the fewest decimal places.
- **Never round in intermediate steps.** Round only in the last step, otherwise
  the error can grow large.
:::

::: sampunkt "Standard form"
- The form $a \cdot 10^{n}$ where $1 \leq a < 10$.
- Numbers less than 1: the exponent is the number of zeros before the first
  non-zero digit, with a minus sign.
- $0.000\,002\,4 = 2.4 \cdot 10^{-6}$.
:::

::: sampunkt "Prefixes"
- Large: k (kilo, $10^{3}$), M (mega, $10^{6}$), G (giga, $10^{9}$),
  T (tera, $10^{12}$).
- Small: d (deci, $10^{-1}$), c (centi, $10^{-2}$), m (milli, $10^{-3}$),
  μ (micro, $10^{-6}$), n (nano, $10^{-9}$), p (pico, $10^{-12}$).
- Replace the power of ten with its prefix: $2.4 \cdot 10^{-6}$ m becomes 2.4 μm.
:::
:::

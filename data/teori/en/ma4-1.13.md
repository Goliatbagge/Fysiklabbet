# The graph of y = tan x

We already know that $\tan x = \dfrac{\sin x}{\cos x}$. A fraction is not
defined when the denominator is $0$, so tangent is not defined where
$\cos x = 0$. That happens for

$$
x = \pm 90^\circ + n \cdot 360^\circ,
$$

which can just as well be written $x = 90^\circ + n \cdot 180^\circ$.

This means that the graph of $y = \tan x$ has **vertical asymptotes**: it
"shoots off" towards infinity exactly where it is not defined, for example
at $90^\circ$, $270^\circ$ and $450^\circ$. Between two asymptotes the
same shape repeats, so the tangent function has the **period $180^\circ$** (or
$\pi$ rad). Drag the graph below and see how the curve rises steeply towards each
asymptote and then starts again.

::: graf
titel: y = \tan x
uttryck: tan(x)
ekvation: y = \tan x
x: -6.5, 6.5
y: -6, 6
:::

Shifts and periods are calculated in the same way as for the sine and
cosine functions. The tangent function, however, has **no amplitude**: a factor
in front of $\tan$ only stretches the curve vertically, it changes neither the period nor
the position of the asymptotes.

::: formel "Period and shift of tan x"
The function $y = \tan(Bx + C) + D$

- has the period $\dfrac{180^\circ}{B}$ or $\dfrac{\pi}{B}$ rad,
- is shifted $-\dfrac{C}{B}$ in the $x$-direction (to the left for $C > 0$ and to the right for $C < 0$),
- is shifted $D$ units in the $y$-direction (up for $D > 0$ and down for $D < 0$).
:::

::: exempel "Example 1: Where is the function undefined?"
**For which values of $x$ is the function $\tan\left(2x + \dfrac{\pi}{3}\right)$ not defined?**

::: handskrift
typ: tanodefinierad
:::

::: textlosning
We rewrite the function using sine and cosine:

$$
\tan\left(2x + \frac{\pi}{3}\right) = \frac{\sin\left(2x + \frac{\pi}{3}\right)}{\cos\left(2x + \frac{\pi}{3}\right)}
$$

The function is not defined when the denominator is $0$. So we investigate when

$$
\cos\left(2x + \frac{\pi}{3}\right) = 0 \quad\Leftrightarrow\quad 2x + \frac{\pi}{3} = \pm\frac{\pi}{2} + n \cdot 2\pi
$$

We solve for $x$:

$$
2x = -\frac{\pi}{3} \pm \frac{\pi}{2} + n \cdot 2\pi \quad\Leftrightarrow\quad x = -\frac{\pi}{6} \pm \frac{\pi}{4} + n \cdot \pi
$$

With the common denominator $12$, $-\dfrac{\pi}{6} = -\dfrac{2\pi}{12}$ and
$\dfrac{\pi}{4} = \dfrac{3\pi}{12}$, so

$$
x_1 = -\frac{2\pi}{12} - \frac{3\pi}{12} + n \cdot \pi = -\frac{5\pi}{12} + n \cdot \pi
$$

$$
x_2 = -\frac{2\pi}{12} + \frac{3\pi}{12} + n \cdot \pi = \frac{\pi}{12} + n \cdot \pi
$$

**Answer:** $x_1 = -\dfrac{5\pi}{12} + n \cdot \pi$ and $x_2 = \dfrac{\pi}{12} + n \cdot \pi$
:::
:::

::: exempel "Example 2: State the period"
**State the period of<br>a)&nbsp;$\tan 5x$&emsp;&emsp;b)&nbsp;$3\tan\dfrac{x}{4}$**

::: handskrift
typ: tanperiod
:::

::: textlosning
The period of $\tan x$ is $180^\circ$. We divide by the coefficient $B$
in front of $x$; the factor in front of $\tan$ does not affect the period.

**a)** Here $B = 5$, so

$$
\frac{180^\circ}{5} = 36^\circ
$$

**b)** Here $B = \dfrac{1}{4}$, so

$$
\frac{180^\circ}{\frac{1}{4}} = 4 \cdot 180^\circ = 720^\circ
$$

**Answer:** a) $36^\circ$&emsp;&emsp;b) $720^\circ$
:::
:::

::: exempel "Example 3: Describe the shift"
**Describe how the graph of the function $y = \tan\left(x - \dfrac{4\pi}{3}\right) - 3$ is shifted compared with the graph of $y = \tan x$.**

::: handskrift
typ: tanforskjutning
:::

::: textlosning
Shifts of $\tan x$ work in the same way as for the sine and
cosine functions. The argument $x - \dfrac{4\pi}{3}$ means that the graph is
shifted $\dfrac{4\pi}{3}$ to the right (since the term is negative), and
the term $-3$ means that it is shifted $3$ steps down.

**Answer:** $\dfrac{4\pi}{3}$ rad to the right and $3$ units down
:::
:::

::: sammanfattning "Summary"

::: sampunkt "Asymptotes"
- $\tan x = \dfrac{\sin x}{\cos x}$ is not defined where $\cos x = 0$.
- That happens for $x = 90^\circ + n \cdot 180^\circ$.
- There the graph has **vertical asymptotes**, that is at $90^\circ$, $270^\circ$, $450^\circ$ and so on.
:::

::: sampunkt "The shape of the graph"
- The curve rises steeply towards each asymptote and then starts again.
- The period is $180^\circ$, that is $\pi$ rad, half that of the sine function.
- The tangent function has **no amplitude**. A factor in front of $\tan$ only stretches the curve vertically.
:::

::: sampunkt "Period and shift"
$y = \tan(Bx + C) + D$
- has the period $\dfrac{180^\circ}{B}$ or $\dfrac{\pi}{B}$ rad,
- is shifted $-\dfrac{C}{B}$ in the $x$-direction: to the left for $C > 0$ and to the right for $C < 0$,
- is shifted $D$ units in the $y$-direction.
- $\tan 5x$ has the period $36^\circ$ and $3\tan \dfrac{x}{4}$ the period $720^\circ$.
:::

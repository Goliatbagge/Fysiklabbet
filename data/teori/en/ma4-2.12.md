# Vertical and horizontal asymptotes

A line that a curve approaches, without reaching it, as the independent variable tends
to infinity or to a certain value is called an **asymptote**. An asymptote
that goes straight up and down is called **vertical** and a level one **horizontal**.

When we study how a function behaves near an $x$-value $a$, we distinguish between
approaching from below and from above. A limit where $x$ tends to $a$
from below is written $\lim\limits_{x \to a^-} f(x)$, and from above
$\lim\limits_{x \to a^+} f(x)$.

## Vertical asymptotes

Vertical asymptotes occur at $x$-values where the function is not defined,
for example when the denominator of a rational function is equal to 0. When the $x$-value
approaches this value, from below or from above, the function tends to positive
infinity $+\infty$ or negative infinity $-\infty$.

::: formel "Vertical asymptote"
The graph of $f(x)$ has a **vertical asymptote** $x = a$ if

$$
\lim_{x \to a^-} f(x) = \pm\infty \qquad \text{or} \qquad \lim_{x \to a^+} f(x) = \pm\infty
$$

Vertical asymptotes of a rational function are calculated by setting
**the denominator equal to 0** and solving the equation.
:::

## Horizontal asymptotes

Horizontal asymptotes occur when a function approaches a definite value
as $x \to \infty$ or $x \to -\infty$ respectively. This often applies to rational
functions.

::: formel "Horizontal asymptote"
The graph of $f(x)$ has a **horizontal asymptote** $y = m$ if

$$
\lim_{x \to -\infty} f(x) = m \qquad \text{or} \qquad \lim_{x \to \infty} f(x) = m
$$

The $y$-value of a horizontal asymptote of a rational function is calculated
by finding the function's limit as $x \to \infty$ or $x \to -\infty$.
:::

If, for example, we study the graph of $f(x) = \dfrac{1}{x - 2} + 1$, we see that
it has a vertical asymptote at $x = 2$, where the denominator is equal to 0.
The function value tends to $-\infty$ as we approach $x = 2$ from below and to
$+\infty$ as we approach from above. The graph also has a horizontal asymptote
at $y = 1$, which is the function's limit as $x \to \pm\infty$. Drag
the slider $a$ and see how the vertical asymptote $x = a$ moves sideways,
and the slider $m$ to move the horizontal asymptote $y = m$ up and down.

::: exempel "Example 1: Vertical and horizontal asymptote separately"
**Find the<br>a) vertical asymptote of $f(x) = \dfrac{5}{8 - 2x}$<br>b) horizontal asymptote of $f(x) = \dfrac{5}{x + 3} + 3$**

::: handskrift
typ: asymptotvh
:::

::: textlosning
**a)** We set the denominator equal to 0 and solve the equation. The solution gives
the equation of the asymptote.

$$
\begin{aligned}
8 - 2x &= 0\\
8 &= 2x\\
x &= 4
\end{aligned}
$$

**b)** We find the function's limit as $x \to \infty$. A rational
expression where $x$ is only in the denominator tends to 0, so

$$
\lim_{x \to \infty} \left( \frac{5}{x + 3} + 3 \right) = 0 + 3 = 3
$$

The limit as $x \to -\infty$ is the same.

**Answer:** a) $x = 4$&emsp;&emsp;b) $y = 3$
:::
:::

::: exempel "Example 2: Both asymptotes of a rational function"
**Find the vertical and the horizontal asymptote of $f(x) = \dfrac{x + 1}{x - 3}$.**

::: handskrift
typ: badaasymptoter
:::

::: textlosning
The vertical asymptote is found where the denominator is equal to 0:

$$
\begin{aligned}
x - 3 &= 0\\
x &= 3
\end{aligned}
$$

The horizontal asymptote is found from the limit as $x \to \infty$. Constant terms
can be neglected (disregarded) in limits as $x \to \infty$, so the numerator and the denominator
both tend to $x$:

$$
\lim_{x \to \infty} \left( \frac{x + 1}{x - 3} \right) = \frac{x}{x} = 1
$$

The limit as $x \to -\infty$ is the same.

**Answer:** $x = 3$ and $y = 1$
:::
:::

::: exempel "Example 3: Asymptote in only one direction"
**Find the horizontal asymptote of $f(x) = 2^{-x} + 7$.**

::: handskrift
typ: asymptotenkelsida
:::

::: textlosning
We find the limit as $x \to \infty$ and as $x \to -\infty$. Since
$2^{-x} = \dfrac{1}{2^{x}}$, the term tends to 0 as $x$ grows:

$$
\lim_{x \to \infty} \left( 2^{-x} + 7 \right) = \lim_{x \to \infty} \left( \frac{1}{2^{x}} + 7 \right) = 0 + 7 = 7
$$

So $y = 7$ is a horizontal asymptote. As $x \to -\infty$ the exponent $-x$
instead becomes positive, so $2^{-x}$ grows without bound:

$$
\lim_{x \to -\infty} \left( 2^{-x} + 7 \right) = \infty
$$

So the function has no horizontal asymptote to the left, but it has one to the right.

**Answer:** $y = 7$ (to the right)
:::
:::

::: sammanfattning "Summary"

::: sampunkt "Asymptote"
- An **asymptote** is a line that the curve approaches without reaching it.
- An asymptote going straight up and down is called **vertical**, a level one is called **horizontal**.
- $\lim_{x \to a^-}$ means that $x$ approaches $a$ from below, $\lim_{x \to a^+}$ from above.
:::

::: sampunkt "Vertical asymptote"
- $x = a$ is a vertical asymptote if $\lim_{x \to a^{\pm}} f(x) = \pm\infty$.
- They occur where the function **is not defined**.
- For a rational function: set **the denominator equal to 0** and solve the equation.
:::

::: sampunkt "Horizontal asymptote"
- $y = m$ is a horizontal asymptote if $\lim_{x \to \pm\infty} f(x) = m$.
- Calculate the limit as $x$ grows without bound.
- Constant terms can be neglected: $\dfrac{x + 1}{x - 3}$ tends to $\dfrac{x}{x} = 1$.
:::

::: sampunkt "In only one direction"
- The limits to the right and left can **differ**. Investigate both.
- $2^{-x} + 7$ tends to 7 as $x \to \infty$, but to infinity as $x \to -\infty$.
- So the function has a horizontal asymptote only to the right.
:::

:::

# The derivative of composite functions and the chain rule

A function of another function is called a **composite function**. If we have
the functions $f(x)$ and $g(x)$, then $f(g(x))$ is a composite function. We
call $f(x)$ the **outer function** and $g(x)$ the **inner
function**. It means that we substitute $g(x)$ into the function $f(x)$. In
the same way $g(f(x))$ is also a composite function, where we instead
substitute $f(x)$ into the function $g(x)$.

If $f(x) = 2x + 3$ and $g(x) = x^2$, then

$$
\begin{aligned}
f(g(x)) &= [\text{we substitute } g(x) = x^2 \text{ into } f(x)] = f(x^2) = 2x^2 + 3\\
g(f(x)) &= [\text{we substitute } f(x) = 2x + 3 \text{ into } g(x)] = g(2x + 3) = (2x + 3)^2 = 4x^2 + 12x + 9
\end{aligned}
$$

So we see that $f(g(x))$ is not the same as $g(f(x))$. Which function
is outer or inner matters.

The rule for differentiating composite functions is called **the chain rule**.

::: formel "The chain rule"
The derivative of a composite function $y = f(g(x))$ is

$$
y' = f'(g(x))\cdot g'(x)
$$

where $f'(g(x))$ is the **outer derivative** and $g'(x)$ the **inner
derivative**. In Leibniz notation, if $y$ depends on $u$ and $u$ on $x$:

$$
\frac{dy}{dx} = \frac{dy}{du}\cdot \frac{du}{dx}
$$
:::

So you first differentiate the outer function and then multiply by
the derivative of the inner function (the expression inside the brackets).

::: exempel "Example 1: Power function, with a check"
**Differentiate $y = (x^2 - 5)^2$.**

::: handskrift
typ: kedjepotens
:::

::: textlosning
The outer function is a power function $z^2$ and the inner function is
what is inside the brackets. We first differentiate the outer function
("bring the exponent down and reduce it by 1") and then multiply
by the derivative of the inner function:

$$
y' = 2(x^2 - 5)\cdot 2x = 4x(x^2 - 5) = 4x^3 - 20x
$$

**Check:** we expand $y$ using the square rule and differentiate as
usual:

$$
y = (x^2 - 5)^2 = (x^2)^2 - 2x^2\cdot 5 + 5^2 = x^4 - 10x^2 + 25
$$

$$
y' = 4x^3 - 20x
$$

This agrees with the answer.

**Answer:** $y' = 4x^3 - 20x$
:::
:::

::: exempel "Example 2: Exponential function"
**Differentiate $y = e^{x^3 - 5}$.**

::: handskrift
typ: kedjeexp
:::

::: textlosning
The outer function is an exponential function $e^z$ and the inner function
is what is in the exponent, $x^3 - 5$. The outer derivative is $e^z$ in
unchanged form; we multiply it by the derivative of the inner function:

$$
y' = e^{x^3 - 5}\cdot 3x^2
$$

**Answer:** $y' = 3x^2 e^{x^3 - 5}$
:::
:::

::: exempel "Example 3: Root function"
**Differentiate $y = \sqrt{x^2 + 3x}$.**

::: handskrift
typ: kedjerot
:::

::: textlosning
The outer function is a root function $\sqrt{z} = z^{1/2}$ and the inner
function is what is under the root sign, $x^2 + 3x$. We start by
rewriting the root expression as a power:

$$
y = \sqrt{x^2 + 3x} = (x^2 + 3x)^{1/2}
$$

Now we use the chain rule, with the inner derivative $2x + 3$:

$$
y' = \frac{1}{2}(x^2 + 3x)^{-1/2}\cdot (2x + 3) = \frac{(x^2 + 3x)^{-1/2}(2x + 3)}{2} = \frac{2x + 3}{2(x^2 + 3x)^{1/2}} = \frac{2x + 3}{2\sqrt{x^2 + 3x}}
$$

**Answer:** $y' = \dfrac{2x + 3}{2\sqrt{x^2 + 3x}}$
:::
:::

::: sammanfattning "Summary"

::: sampunkt "Composite function"
- A function of another function, $f(g(x))$, is called **composite**.
- $f(x)$ is the **outer** function and $g(x)$ the **inner** one.
- The order matters: $f(g(x))$ is not the same thing as $g(f(x))$.
:::

::: sampunkt "The chain rule"
- $y = f(g(x))$ gives $y' = f'(g(x)) \cdot g'(x)$.
- In words: **outer derivative times inner derivative**.
- In Leibniz notation: $\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}$.
:::

::: sampunkt "Finding the outer and inner function"
- **Brackets raised to a power:** the inner function is what is inside the brackets.
- **Exponential function:** the inner function is the exponent.
- **Root function:** the inner function is what is under the root sign. Rewrite the root as a power first.
:::

::: sampunkt "Typical examples"
- $y = e^{x^3 - 5}$ gives $y' = 3x^2 e^{x^3 - 5}$.
- $y = \sqrt{x^2 + 3x} = (x^2 + 3x)^{1/2}$ gives $y' = \dfrac{2x + 3}{2\sqrt{x^2 + 3x}}$.
- If the expression can be expanded, you can check the answer with the ordinary rule.
:::

:::

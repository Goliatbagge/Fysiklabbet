# Physics as a subject: introduction

The word "physics" comes from the Greek "physikos", which means *nature*. The
task of physics is to try to describe how matter is built up and which laws
govern matter. Physics tries to describe *how* something happens, but that does
not necessarily mean that we know *why*.

In physics we use the **scientific method** to gain more knowledge about
nature. The scientific method consists of several steps:

- **Observation**: we see how something behaves.
- **Hypothesis**: we guess how we could explain the observation.
- **Testing the hypothesis**: we test our hypothesis, usually with experiments.
- **Laws and theories**: if the experiments support our hypothesis.

If a **hypothesis** has been through several experiments without being
disproved, the hypothesis becomes a **law**. Several laws together form a
**theory**.

::: tips "Theory means something else in physics"
In everyday speech the word "theory" is used for something that is very
uncertain, something that is a guess. But a physical or scientific theory is,
on the contrary, very certain, because it has been carefully tested and never
disproved.
:::

Real phenomena can be hard to describe exactly in detail, but we can then
create **models** that agree well enough with what we observe.

::: sammanfattning "Summary"

::: sampunkt "What physics does"
- The word physics comes from the Greek *physikos*, which means nature.
- Physics describes how matter is built up and the laws that govern it.
- It answers **how** something happens. Knowing how does not mean that we
  know why.
:::

::: sampunkt "The scientific method"
1. **Observation**: we see how something behaves.
2. **Hypothesis**: we guess an explanation.
3. **Testing the hypothesis**: we test the hypothesis, usually with experiments.
4. **Laws and theories**: if the experiments support the hypothesis.
:::

::: sampunkt "Hypothesis, law and theory"
- A **hypothesis** that has been tested many times without being disproved
  becomes a **law**.
- Several laws together form a **theory**.
- In everyday language a theory means a loose guess. In physics it is the
  other way round: a theory has been carefully tested and is therefore very
  certain.
:::

::: sampunkt "Models"
- Real phenomena are often too complicated to describe exactly.
- We then build a **model** that agrees well enough with what we
  observe.
:::
:::

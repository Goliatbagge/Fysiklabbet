# Subtraction of vectors

::: formel "Subtraction of vectors"
A subtraction of vectors is rewritten as an addition according to

$$
\vec{u} - \vec{v} = \vec{u} + (-\vec{v})
$$

So we add the opposite vector, which is then calculated by
translation as before.
:::

::: sammanfattning "Summary"

::: sampunkt "Subtraction becomes addition"
- $\vec{u} - \vec{v} = \vec{u} + (-\vec{v})$
- So: **reverse the vector that is to be subtracted** and add as
  usual.
:::

::: sampunkt "How to draw"
1. Draw $-\vec{v}$, that is $\vec{v}$ with the **reversed** direction.
2. Translate it to the tip of $\vec{u}$.
3. Draw the resultant from the start of $\vec{u}$ to the new tip.
:::

::: sampunkt "The order matters here"
- $\vec{u} - \vec{v}$ and $\vec{v} - \vec{u}$ are **opposite** vectors.
- They are equally long but point in opposite directions. Read the task carefully.
:::
:::

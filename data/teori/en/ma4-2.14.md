# Curve sketching using asymptotes

When we are going to sketch the graph of more advanced functions, for example
rational functions, it helps if we first draw in the asymptotes.
Otherwise we follow the same procedure as before for sketching graphs, that
is we make a sign table.

Besides the $x$-coordinates where the derivative is equal to $0$, we now also enter the
$x$-coordinates where the function **is not defined** in the sign table (see
the example further down).

::: formel "Curve sketching using asymptotes"
1. Find all the asymptotes and draw them as dashed lines in a coordinate system.
2. Find the stationary points and make a sign table according to the earlier procedure.
:::

Try for yourself what a rational function of the same type looks like. Drag the slider for
$c$ and see how the curve keeps creeping towards the oblique asymptote $y = x$
and the vertical asymptote $x = 0$. With $c = 1$ you get the function in Example 1.

::: graf

::: exempel "Example 1: Sketch the graph of a rational function"
**Sketch the graph of $f(x) = \dfrac{x^2 + 1}{x}$.**

**Step 1: We start by finding all the asymptotes.**

::: handskrift
typ: skissrationell
:::

::: textlosning
*Vertical:* The expression cannot be simplified, so we set the denominator $x$ equal to
$0$. We then get $x = 0$ as a **vertical asymptote**.

*Horizontal:* We investigate the limit as $x$ grows without bound:

$$
y = \lim_{x\to\infty}\left(\frac{x^2 + 1}{x}\right) = \lim_{x\to\infty}\left(\frac{x^2}{x} + \frac{1}{x}\right) = \lim_{x\to\infty}\left(x + \frac{1}{x}\right) = \infty + 0 = \infty
$$

There is no limit $\Rightarrow$ **there is no horizontal asymptote**.

*Oblique:* We rewrite the function in the form $f(x) = (kx + m) + R(x)$ by
splitting the expression into several terms:

$$
f(x) = \frac{x^2 + 1}{x} = \frac{x^2}{x} + \frac{1}{x} = x + \frac{1}{x}
$$

We then get $y = x$ as an **oblique asymptote**.

**Step 2: We find the stationary points and make a sign table.**

We differentiate the function and set the derivative equal to $0$. The quotient rule gives:

$$
f'(x) = \frac{2x\cdot x - (x^2 + 1)\cdot 1}{x^2} = \frac{2x^2 - x^2 - 1}{x^2} = \frac{x^2 - 1}{x^2}
$$

$f'(x) = 0$ gives:

$$
\frac{x^2 - 1}{x^2} = 0 \quad\Rightarrow\quad x^2 - 1 = 0 \quad\Rightarrow\quad x^2 = 1 \quad\Rightarrow\quad x = \pm 1
$$

So we have extreme points or stationary points of inflection at $x = -1$ and $x = 1$. We
substitute these $x$-coordinates into the original function to get
the corresponding $y$-coordinates:

$$
f(-1) = \frac{(-1)^2 + 1}{-1} = \frac{1 + 1}{-1} = \frac{2}{-1} = -2
$$

$$
f(1) = \frac{1^2 + 1}{1} = \frac{2}{1} = 2
$$

So the points $(-1,\ -2)$ and $(1,\ 2)$ are points where the slope is $0$.

We investigate the sign of the derivative to the left and right of these values, and
around $x = 0$, where the function is not defined, by substituting some
test values into the derivative $f'(x) = \dfrac{x^2 - 1}{x^2}$:

$$
f'(-2) = \frac{(-2)^2 - 1}{(-2)^2} = \frac{4 - 1}{4} = \frac{3}{4} > 0
$$

$$
f'(-0.5) = \frac{(-0.5)^2 - 1}{(-0.5)^2} = \frac{0.25 - 1}{0.25} = \frac{-0.75}{0.25} < 0
$$

$$
f'(0.5) = \frac{0.5^2 - 1}{0.5^2} = \frac{0.25 - 1}{0.25} = \frac{-0.75}{0.25} < 0
$$

$$
f'(2) = \frac{2^2 - 1}{2^2} = \frac{4 - 1}{4} = \frac{3}{4} > 0
$$

We fill in the signs and draw the corresponding arrows in the last row of the table.
Remember that the function **is not defined** for $x = 0$ (vertical asymptote):

| $x$ | | $-1$ | | $0$ | | $1$ | |
|---|---|---|---|---|---|---|---|
| $f'(x)$ | $+$ | $0$ | $-$ | undef. | $-$ | $0$ | $+$ |
| $f(x)$ | ↗ | $-2$ | ↘ | | ↘ | $2$ | ↗ |

We see from the sign table that we have a **maximum point** at $(-1,\ -2)$ and a
**minimum point** at $(1,\ 2)$. Finally we draw in the bends around these
points and let the branches of the graph approach the respective asymptote more and more.

**Answer:** The graph has the vertical asymptote $x = 0$ and the oblique asymptote
$y = x$, a maximum point at $(-1,\ -2)$ and a minimum point at $(1,\ 2)$.
:::
:::

::: exempel "Example 2: Find all the asymptotes"
**Find all the asymptotes of $g(x) = \dfrac{2x^2 + 1}{x}$.**

::: handskrift
typ: samtligaasymptoter
:::

::: textlosning
*Vertical:* The expression cannot be simplified, so we set the denominator equal to $0$
and get $x = 0$ as a vertical asymptote.

*Horizontal:* As $x$ grows without bound,

$$
\lim_{x\to\infty}\left(\frac{2x^2 + 1}{x}\right) = \lim_{x\to\infty}\left(2x + \frac{1}{x}\right) = \infty
$$

There is no limit, so there is no horizontal asymptote.

*Oblique:* We split the expression into terms:

$$
g(x) = \frac{2x^2 + 1}{x} = \frac{2x^2}{x} + \frac{1}{x} = 2x + \frac{1}{x}
$$

The remainder term $\dfrac{1}{x}$ tends to $0$ as $x$ grows, so $y = 2x$ is an oblique asymptote.

**Answer:** Vertical asymptote $x = 0$ and oblique asymptote $y = 2x$; no
horizontal asymptote.
:::
:::

::: sammanfattning "Summary"

::: sampunkt "The method"
1. Find **all** the asymptotes and draw them as dashed lines in the coordinate system.
2. Find the stationary points and make a sign table as usual.
3. Sketch the curve so that it creeps towards the asymptotes.
:::

::: sampunkt "Look for all three kinds"
- **Vertical:** set the denominator equal to 0, simplifying the expression first if possible.
- **Horizontal:** investigate the limit as $x \to \pm\infty$. If there is no limit, there is no horizontal asymptote.
- **Oblique:** split the fraction and read off $kx + m$.
:::

::: sampunkt "The sign table"
- Enter **both** the zeros of the derivative and the $x$-values where the function **is not defined**.
- The curve can change direction at an asymptote too, without the derivative being zero there.
- Investigate the sign in each subinterval that arises.
:::

::: sampunkt "Typical example"
- $f(x) = \dfrac{x^2 + 1}{x} = x + \dfrac{1}{x}$ has the vertical asymptote $x = 0$ and the oblique one $y = x$.
- There is no horizontal asymptote, since the limit tends to infinity.
- The quotient rule gives $f'(x) = \dfrac{x^2 - 1}{x^2}$, so stationary points at $x = \pm 1$.
:::

:::

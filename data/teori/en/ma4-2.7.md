# The product rule and the quotient rule

When we differentiate a function that consists of several **terms** (a sum), we have
learnt that the derivative is given by the derivatives of the individual terms: we "differentiate
term by term". But how does the derivative of a **product** work?

We investigate the derivative of $y = 2x^3\cdot 5x^2$. If, in the same way
as for a sum, we were to differentiate factor by factor, the derivative would be

$$
y' = 6x^2\cdot 10x = 60x^3
$$

We check whether that is correct by first rewriting the expression so that we
can apply rules of differentiation we already know. Since
$y = 2x^3\cdot 5x^2 = 10x^5$, the power rule gives

$$
y' = 50x^4
$$

So the correct derivative is $y' = 50x^4$. The first method, "factor by
factor", did not work, since $60x^3 \ne 50x^4$. The rule for differentiating
products is called **the product rule**.

::: formel "The product rule"
If $y = f(x)\cdot g(x)$, then
$$
y' = f'(x)\cdot g(x) + f(x)\cdot g'(x)
$$
:::

We check that the product rule works for the example above. Here
$f(x) = 2x^3$ and $g(x) = 5x^2$, so $f'(x) = 6x^2$ and $g'(x) = 10x$.
The product rule then gives

$$
y' = 6x^2\cdot 5x^2 + 2x^3\cdot 10x = 30x^4 + 20x^4 = 50x^4
$$

which agrees with the correct expression. The rule for differentiating
**quotients** is called **the quotient rule**.

::: formel "The quotient rule"
If $y = \dfrac{f(x)}{g(x)}$, then
$$
y' = \frac{f'(x)\cdot g(x) - f(x)\cdot g'(x)}{\bigl(g(x)\bigr)^2}
$$
:::

## The derivative of tan x

With the quotient rule we can derive the derivative of $\tan x$. We write
$\tan x = \dfrac{\sin x}{\cos x}$ and set $f(x) = \sin x$ and
$g(x) = \cos x$, so that $f'(x) = \cos x$ and $g'(x) = -\sin x$. The quotient rule gives

$$
\begin{aligned}
D(\tan x) &= \frac{\cos x\cdot \cos x - \sin x\cdot(-\sin x)}{\cos^2 x}
= \frac{\cos^2 x + \sin^2 x}{\cos^2 x}
\end{aligned}
$$

With the Pythagorean identity $\sin^2 x + \cos^2 x = 1$ the numerator becomes $1$, so
$D(\tan x) = \dfrac{1}{\cos^2 x}$. If we instead split the fraction term by term,
we get the other form:

$$
\frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{\cos^2 x}{\cos^2 x} + \frac{\sin^2 x}{\cos^2 x} = 1 + \tan^2 x
$$

::: formel "The derivative of tan x"
If $f(x) = \tan x$, then
$$
f'(x) = \frac{1}{\cos^2 x} = 1 + \tan^2 x
$$
:::

::: exempel "Example 1: The product rule"
**Differentiate $y = x^2\cdot \sin 2x$.**

::: handskrift
typ: produktregeln
:::

::: textlosning
Here $f(x) = x^2$ and $g(x) = \sin 2x$, so $f'(x) = 2x$ and
$g'(x) = 2\cos 2x$ (the chain rule on $\sin 2x$). The product rule gives

$$
\begin{aligned}
y' &= 2x\cdot \sin 2x + x^2\cdot 2\cos 2x\\
&= 2x\sin 2x + 2x^2\cos 2x
\end{aligned}
$$

**Answer:** $y' = 2x\sin 2x + 2x^2\cos 2x$
:::
:::

::: exempel "Example 2: The quotient rule"
**Differentiate $y = \dfrac{\sin x}{3x^2 - 5}$.**

::: handskrift
typ: kvotregeln
:::

::: textlosning
Here $f(x) = \sin x$ and $g(x) = 3x^2 - 5$, so $f'(x) = \cos x$ and
$g'(x) = 6x$. The quotient rule gives

$$
y' = \frac{\cos x\,(3x^2 - 5) - \sin x\cdot 6x}{(3x^2 - 5)^2}
$$

**Answer:** $y' = \dfrac{(3x^2 - 5)\cos x - 6x\sin x}{(3x^2 - 5)^2}$
:::
:::

::: exempel "Example 3: The quotient rule with e and ln"
**Differentiate $y = \dfrac{\ln x}{e^{2x}}$.**

::: handskrift
typ: kvotexpln
:::

::: textlosning
Here $f(x) = \ln x$ and $g(x) = e^{2x}$, so $f'(x) = \dfrac{1}{x}$ and
$g'(x) = 2e^{2x}$. The quotient rule gives

$$
y' = \frac{\dfrac{1}{x}\cdot e^{2x} - \ln x\cdot 2e^{2x}}{\bigl(e^{2x}\bigr)^2}
$$

The denominator is $\bigl(e^{2x}\bigr)^2 = e^{4x}$. We take out $e^{2x}$ in the numerator
and cancel it against the denominator:

$$
= \frac{e^{2x}\left(\dfrac{1}{x} - 2\ln x\right)}{e^{4x}} = \frac{\dfrac{1}{x} - 2\ln x}{e^{2x}} = \frac{1 - 2x\ln x}{x\,e^{2x}}
$$

**Answer:** $y' = \dfrac{1 - 2x\ln x}{x\,e^{2x}}$
:::
:::

::: sammanfattning "Summary"

::: sampunkt "The product rule"
- $y = f(x) \cdot g(x)$ gives $y' = f'(x)g(x) + f(x)g'(x)$.
- You **cannot** differentiate factor by factor. That gives the wrong answer.
- It is a good idea to check on an expression that can also be rewritten and differentiated directly.
:::

::: sampunkt "The quotient rule"
- $y = \dfrac{f(x)}{g(x)}$ gives $y' = \dfrac{f'(x)g(x) - f(x)g'(x)}{\big(g(x)\big)^2}$.
- The order in the numerator matters, since there is a **minus**.
- The denominator is the whole original denominator squared.
:::

::: sampunkt "Method"
1. Name $f(x)$ and $g(x)$.
2. Differentiate each one separately, often with the chain rule.
3. Substitute into the rule and simplify.
:::

::: sampunkt "Simplifying"
- Take out common factors in the numerator and cancel against the denominator.
- $\big(e^{2x}\big)^2 = e^{4x}$, so a factor $e^{2x}$ can be cancelled.
- With the quotient rule the derivative of $\tan x = \dfrac{\sin x}{\cos x}$ can be derived.
:::

:::

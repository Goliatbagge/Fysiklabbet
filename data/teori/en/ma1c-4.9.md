# Solving equations with graphing tools

We can solve equations using graphs with graphing tools,
for example GeoGebra. We then make a **graphical solution**.

::: formel "Solving equations with graphing tools"
We have an equation LHS = RHS.

1. Draw the equations $y = \mathrm{LHS}$ and $y = \mathrm{RHS}$ in
   GeoGebra.
2. Find the point of intersection and read off its *x*-coordinate. This is
   the solution!
:::

::: exempel "Example 1: Graphical solution of an equation"
**Use a graphing tool to solve the equation $3x - 5 = -x + 3$.**

:::

We now need to decide when $-2x + 5$ is LESS THAN $x - 4$.

$-2x + 5$ is LESS THAN $x - 4$ when the line $y = -2x + 5$ lies *below*
the line $y = x - 4$. It does so *to the right* of the point of intersection, that is,
when $x > 3$.

**Answer:** $x > 3$
:::

::: härledning "GeoGebra: tips"
**Decimal numbers**

Decimal numbers in GeoGebra are written with a point (.), not a decimal comma (,) as in Swedish.
If you want to draw the line $y = 7.5x + 3$ in GeoGebra you should therefore
type `y = 7.5x + 3`. Note the difference: **7,5 is written 7.5**.

**Variables**

In graphical solutions GeoGebra only "understands" the variables $x$ and $y$. If
we, for example, want to enter the equation $y = 13t + 5$, we need to replace
the variable $t$ with $x$ and enter the left-hand side as $y = 13x + 5$:
**$y = 13t + 5$ is entered as `y = 13x + 5`**.
:::

::: sammanfattning "Summary"

::: sampunkt "Graphical solution"
1. Draw $y = \mathrm{LHS}$ and $y = \mathrm{RHS}$ as two separate graphs.
2. Find the **point of intersection**.
3. The **$x$-coordinate** of the point of intersection is the solution.
:::

::: sampunkt "Inequalities graphically"
- Draw both sides in the same way.
- Read off **the interval** where one graph lies above or below
  the other.
- $-2x + 5 < x - 4$ has the intersection at $x = 3$, and the answer is
  $x > 3$.
:::

::: sampunkt "GeoGebra: decimal numbers"
- Type a **point** instead of a decimal comma.
- $y = 7.5x + 3$ is entered as `y = 7.5x + 3`.
:::

::: sampunkt "GeoGebra: variables"
- The program only understands $x$ and $y$ in graphical solutions.
- $y = 13t + 5$ must be entered as `y = 13x + 5`.
- Remember to **translate the answer back** to the original variable.
:::

::: sampunkt "Showing your work"
- Always write down **what you did**: which graphs you drew and where they
  intersected.
- A point of intersection read off the graph is a perfectly good answer, but the justification must
  be there.
:::
:::
